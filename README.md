## How to Use

1. **Open `index.html`** in any modern browser to view the public website.
2. **Bilingual**: Click the language switcher (العربية / English) in the header. The entire site switches direction and text.
3. **Admin Dashboard**: Open `admin.html`
   - Email: `yassinossama@yahoo.com`
